# Datelia

Sitio web de Datelia — agencia de Inteligencia Artificial aplicada a los negocios.

Next.js 15 (App Router) + TypeScript + Tailwind/shadcn + Supabase. Ver `DEVELOPER_GUIDE.md` para el detalle de arquitectura, flujo de contenidos y variables de entorno, y `CLAUDE.md` para el panorama orientado a agentes (stack, estructura, grafo de conocimiento).

## Desarrollo local

```bash
npm install
npm run dev
```
